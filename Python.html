1 Introduction

Python is a high-level, interpreted, general-purpose programming language known for clean, readable syntax that reads almost like plain English. It emphasizes code readability and lets developers express ideas in fewer lines than many other languages.

Python is used everywhere — web backends, data science, machine learning, automation scripting, and more. Its huge standard library ("batteries included") and massive third-party ecosystem (PyPI) make it a go-to first language for beginners and a serious production tool for experts.

    4 File Structure

    Python files use the .py extension and run directly through the interpreter — no compilation step needed.

    # app.py — typical structure
import os                     # 1. imports
APP_NAME = "Demo"            # 2. constants

def main():                   # 3. logic
    print(APP_NAME)

if __name__ == "__main__": # 4. entry point
    main()
  • if __name__ == "__main__": ensures code only runs when the file is executed directly, not when imported.

    12 Classes

    class Animal:
    def __init__(self, name):   # constructor
        self.name = name
    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):                # inheritance
    def speak(self):
        return f"{self.name} barks"   # override

d = Dog("Rex")
d.speak()  # "Rex barks"
  • __init__ is the constructor, called automatically on instantiation.
  • self refers to the instance itself.
  • Dog(Animal) means Dog inherits from Animal.

    • 19 Memory Management

    Python manages memory automatically via reference counting plus a cyclic garbage collector for circular references. CPython frees an object as soon as its reference count drops to zero.

    import sys
a = []
sys.getrefcount(a)  # check reference count

    20 Performance

    • Use built-in functions and comprehensions — they're implemented in C and faster than manual loops.
    • Avoid unnecessary object creation in hot loops.
    • Use multiprocessing for CPU-bound work (the GIL limits threads for this).
    • Profile with cProfile before optimizing.
    squares = [x**2 for x in range(1000)]  # list comprehension — fast

    21 Best Practices

    • Follow PEP 8 style conventions.
    • Use virtual environments (venv) per project.
    • Prefer list/dict comprehensions over manual loops when readable.
    • Write docstrings for public functions and classes.

    22 Security

    • Never use eval() or pickle.loads() on untrusted input.
    • Use parameterized queries to prevent SQL injection.
    • Keep dependencies updated — check with pip-audit.
    # Bad
eval(user_input)
# Better — use ast.literal_eval for safe literals only
import ast
ast.literal_eval(user_input)

    27 Common Mistakes

    • Using a mutable default argument, e.g. def f(items=[]): — shared across calls.
    • Confusing is with == for value comparison.
    • Not closing files/resources — prefer with open(...) as f:.
    • Catching bare except: and swallowing real errors.

    28 Interview Questions

    Q: What is the GIL?
    A: The Global Interpreter Lock — allows only one thread to execute Python bytecode at a time in CPython, limiting true parallelism for CPU-bound threads.
    Q: Difference between a list and a tuple?
    A: Lists are mutable; tuples are immutable. Tuples can be used as dictionary keys, lists cannot.
    Q: What are generators?
    A: Functions using yield that produce values lazily, one at a time, without holding the whole sequence in memory.

    32 FAQ

    Is Python slow?
    Compared to compiled languages, yes for raw loops — but C-backed libraries (NumPy, Pandas) make heavy computation fast in practice.
    Python 2 or 3?
    Always Python 3 — Python 2 reached end of life in 2020.
