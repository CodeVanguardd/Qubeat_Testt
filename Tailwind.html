Tailwind CSS

A utility-first CSS framework for building custom designs fast — compose small, single-purpose classes right in your markup instead of writing new CSS.

1 Introduction

Tailwind CSS is a utility-first CSS framework: instead of writing custom class names and CSS rules, you compose small, single-purpose utility classes directly in your HTML — flex, p-4, text-center — to build designs fast without leaving the markup.

It ships no pre-built components by default; instead it gives you low-level building blocks and a design system (spacing scale, colors, typography) that keeps everything consistent.

Type
Utility-first CSS framework
Runs on
Any HTML/JS project via build tool
Paradigm
Compositional, utility classes
<button class="px-4 py-2 bg-pink-600 text-white rounded-lg">
  Click me
</button>
  • px-4 py-2 sets padding on x and y axes using Tailwind's spacing scale.
  • bg-pink-600 and text-white set background and text color.
  • rounded-lg applies a border-radius utility.

    4 File Structure

    Tailwind is configured via tailwind.config.js and applied through directives in your main CSS file.

    /* input.css */
@tailwind base;
@tailwind components;
@tailwind utilities;
    // tailwind.config.js
module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: { extend: {} },
};

  • Composing many small classes replaces writing custom CSS rules.

    • 13 Objects (Component Extraction)

    When a utility combo repeats, extract it into a component class or a framework component (React/Vue) rather than repeating long class strings.

    function Button({ children }) {
  return <button className="px-4 py-2 bg-pink-600 rounded-lg">{children}</button>;
}

    18 Error Handling (Build Issues)

    • Classes not generated? Check your content paths in the config — Tailwind only scans files it's told to.
    • Arbitrary values with spaces need underscores: grid-cols-[1fr_2fr], not a literal space.

    19 Memory Management (Bundle Size)

    Tailwind's JIT/Oxide engine only generates CSS for classes actually found in your source files, keeping the final CSS bundle small regardless of how many utilities exist in the framework.

    20 Performance

    • Purge unused styles automatically via content scanning (on by default in v3+).
    • Avoid excessive arbitrary values that bypass the design scale and bloat CSS.
    • Use @apply sparingly — it can reintroduce specificity issues.

    21 Best Practices

    • Stick to the design scale (spacing, colors) instead of arbitrary values when possible.
    • Extract repeated class groups into components, not @apply everywhere.
    • Use responsive and state prefixes instead of custom media queries.

    22 Security

    • Tailwind itself introduces no runtime — it's pure CSS, so there's no JS execution risk.
    • Be careful with dynamically constructed class strings from user input — Tailwind can't purge classes it can't statically find.

    23 Accessibility

    • Use the sr-only utility for screen-reader-only text.
    • Don't rely on color utilities alone — pair with icons/text for state.
    • Respect motion-reduce: variant for animations.
    <span class="sr-only">Close menu</span>

    24 Code Style

    • Order classes logically: layout → spacing → typography → color → state.
    • Use the official Prettier plugin to auto-sort class order.
    • Keep class lists readable — break long lists across lines in JSX.

    25 Design Patterns

    27 Common Mistakes

    • Forgetting to include all file paths in the content config — styles silently missing.
    • Fighting the framework with too many arbitrary values instead of extending the theme.
    • Overusing @apply, losing the benefits of utility composition.

    28 Interview Questions

    Q: What is "utility-first" CSS?
    A: Styling elements by composing many small, single-purpose classes directly in markup, instead of writing custom CSS classes per component.
    Q: How does Tailwind keep bundle size small?
    A: Its JIT/Oxide engine scans your source files and only generates CSS for the classes actually used.

    32 FAQ

    Do I still need to know CSS?
    Yes — Tailwind is built on CSS concepts (box model, flexbox, grid); it just gives you a faster way to apply them.
    Does Tailwind bloat my HTML?
    Class lists can get long, but component extraction (React/Vue) usually keeps things manageable.
