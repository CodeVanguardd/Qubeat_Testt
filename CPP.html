C++

A high-performance systems language with object-oriented and generic programming built on top of C — the language of game engines and demanding software.

1 Introduction

C++ is a high-performance, multi-paradigm language that extends C with object-oriented, generic, and (later) functional programming features, while preserving low-level memory control. It's used wherever performance and hardware-level control matter greatly.

C++ balances raw speed with abstraction, letting developers write both close-to-the-metal code and organized, reusable, object-oriented systems.

12 Classes

class Animal {
protected:
  std::string name;
public:
  Animal(std::string n) : name(n) {}
  virtual std::string speak() { return name + " makes a sound"; }
};
class Dog : public Animal {
public:
  Dog(std::string n) : Animal(n) {}
  std::string speak() override { return name + " barks"; }
};

19 Memory Management

C++ supports manual memory (new/delete) plus RAII and smart pointers to automate cleanup safely.

std::unique_ptr<int> p = std::make_unique<int>(5);
// auto-freed when p goes out of scope

20 Performance

  • Prefer stack allocation over heap when possible.
  • Use move semantics (std::move) to avoid unnecessary copies.

21 Best Practices

  • Prefer smart pointers over raw new/delete.
  • Follow RAII — tie resource lifetime to object scope.

22 Security

  • Avoid buffer overflows — prefer std::vector/std::array over raw arrays.
  • Watch for dangling pointers and use-after-free bugs.

23 Accessibility

28 Interview Questions

Q: What is RAII?
A: Resource Acquisition Is Initialization — tying resource cleanup to object destruction for automatic, safe release.
Q: Stack vs heap?
A: Stack is fast, automatically managed, limited size; heap is manually managed, larger, slower to allocate.
