JavaScript

The language of the web — dynamic, event-driven, and everywhere. From syntax to async patterns, classes, and where the language is headed next.

1 Introduction

JavaScript is a high-level, interpreted, multi-paradigm programming language most famous as the scripting language of web browsers. It lets developers add interactivity, logic, and dynamic behavior to otherwise static HTML pages — from validating a form to rendering an entire application. Outside the browser, JavaScript (via Node.js) also powers servers, command-line tools, mobile apps, and desktop software.

What makes JavaScript distinctive is its flexibility: it supports procedural, object-oriented, and functional programming styles, uses dynamic typing, and treats functions as first-class citizens. It's single-threaded but handles concurrency through an event loop, making it well suited for I/O-heavy, interactive applications.

    • 2 History

    4 File Structure

    JavaScript files use the .js extension (or .mjs for native ES modules, .cjs for CommonJS). A file can be linked to HTML or run directly with Node.js.

    <script src="app.js" defer></script>
  • src points to the external JS file.
  • defer tells the browser to run the script only after the HTML is parsed.
    • // app.js — typical structure
import { greet } from './utils.js'; // 1. imports
const APP_NAME = 'Demo';             // 2. constants
function init() { greet(APP_NAME); }  // 3. logic
init();                                     // 4. execution

    11 Functions

    Example 1 — Declaration

  return a + b; // sum returned to caller

    Example 2 — Arrow + default params

    const greet = (name = "Guest") => `Hi, ${name}`;

  • Arrow functions don't bind their own this — useful inside callbacks.
  • Default parameters fill in values when an argument is omitted.

    • 12 Classes

    class Animal {
  constructor(name) { this.name = name; }   // runs on 'new'
  speak() { return `${this.name} makes a sound`; }
}
class Dog extends Animal {                    // inheritance
  speak() { return `${this.name} barks`; }  // override
}
const d = new Dog("Rex");
d.speak(); // "Rex barks"
  • constructor initializes new instances.
  • extends sets up prototype-based inheritance.
  • Overriding speak() in Dog replaces the parent's method for that subclass.

    18 Error Handling

    try {
  const data = JSON.parse(badJSON); // may throw
} catch (err) {
  console.error("Failed:", err.message); // handle
} finally {
  console.log("Done");       // always runs
}
  • try wraps risky code.
  • catch receives the thrown error object.
  • finally runs regardless of success or failure.

    • 19 Memory Management

    JavaScript uses automatic garbage collection (mark-and-sweep). Memory is freed when objects are no longer reachable from any reference.

    let obj = { big: new Array(1000000) };
obj = null; // no more references → eligible for GC

    Common leaks: forgotten timers, detached DOM references, and growing closures that hold onto large objects.

    20 Performance

    • Avoid unnecessary re-renders/DOM writes — batch them.
    • Use const/let over var for predictable scoping and JIT optimization.
    • Debounce/throttle expensive event handlers (scroll, resize).
    • Use Web Workers for CPU-heavy tasks off the main thread.
    function debounce(fn, ms) {
  let t;
  return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); };
}

    21 Best Practices

    • Prefer const, use let only when reassignment is needed.
    • Use strict equality === instead of ==.
    • Keep functions small and single-purpose.
    • Name things by intent: isLoading, not flag.
    • Handle promise rejections — never leave a floating .then() without .catch().

    22 Security

    • XSS: never inject unsanitized HTML via innerHTML.
    • Avoid eval() — it executes arbitrary strings as code.
    • Validate input on the server, not just the client.
    • Use HTTPS and secure, HttpOnly cookies for sensitive data.
    // Bad — vulnerable to XSS
el.innerHTML = userInput;
// Better
el.textContent = userInput;

    23 Accessibility

    • Use semantic HTML elements before reaching for JS-driven widgets.
    • Manage focus when opening modals or dynamic content.
    • Add ARIA attributes only when native semantics fall short.
    btn.setAttribute('aria-expanded', 'true');
modal.focus();

    27 Common Mistakes

    • Using == instead of === causes type coercion bugs.
    • Forgetting await on a promise, causing silent [object Promise] bugs.
    • Mutating state directly instead of creating a new copy.
    • Not handling this binding in regular (non-arrow) callbacks.

    28 Interview Questions

    Q: Difference between let, const, and var?
    A: var is function-scoped and hoisted; let/const are block-scoped. const can't be reassigned.
    Q: What is closure?
    A: A function that "remembers" variables from its enclosing scope even after that scope has finished executing.
    Q: Explain the event loop.
    A: JS runs on a single thread; the event loop moves completed async callbacks (from the task/microtask queues) back onto the call stack when it's empty.

    32 FAQ

    Is JavaScript the same as Java?
    No — only the name is similar; they're unrelated languages.
    Do I need Node.js to write JS?
    No, but you need it to run JS outside the browser (servers, tooling).

    36 Future of the Language

    JavaScript continues evolving through annual ECMAScript releases, with growing focus on pattern matching proposals, better decorators, and tighter integration with WebAssembly for performance-critical code. Its role as the universal language of the web — and increasingly the server — keeps it central to software development.
