1 Introduction

Java is a general-purpose, class-based, object-oriented programming language designed to be portable: "write once, run anywhere." Code compiles to bytecode that runs on the Java Virtual Machine (JVM), which exists for nearly every platform.

Java is known for strict typing, automatic memory management, and a huge standard library, making it a backbone of enterprise software, Android development, and large-scale backend systems.

    4 File Structure

    Java files use .java and must be named after the public class they contain. Compilation produces .class bytecode files.

    // File: Main.java
package com.example.app;      // 1. package
import java.util.List;       // 2. imports
public class Main {          // 3. class body
  public static void main(String[] args) {}
}

    19 Memory Management

    Java uses automatic garbage collection on the JVM heap. Objects with no remaining references become eligible for collection.

    Dog d = new Dog("Rex");
d = null; // eligible for GC

    20 Performance

    • Use StringBuilder for heavy string concatenation.
    • Prefer primitive types over boxed types (int vs Integer) in hot loops.
    • Tune JVM heap/GC settings for large applications.

    21 Best Practices

    • Follow the single-responsibility principle per class.
    • Use interfaces to decouple implementation.
    • Prefer immutability (final) where possible.

    22 Security

    • Validate all external input to prevent injection attacks.
    • Use prepared statements for SQL, never string concatenation.
    • Keep dependencies patched (many CVEs target outdated libraries).

    23 Accessibility

    For Java Swing/JavaFX desktop apps: set accessible names on components and support keyboard navigation.

    24 Code Style

    • PascalCase for classes, camelCase for methods/variables.
    • One public class per file, matching the filename.

    28 Interview Questions

    Q: JVM vs JDK vs JRE?
    A: JVM runs bytecode; JRE is JVM + libraries to run apps; JDK is JRE + compiler and tools to develop apps.
    Q: What is polymorphism in Java?
    A: The ability of a subclass to override and provide a different implementation of a parent's method.
