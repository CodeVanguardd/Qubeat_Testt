TypeScript

A strongly typed superset of JavaScript that adds compile-time safety, interfaces, and generics — built for large, maintainable codebases.

1 Introduction

TypeScript is a strongly typed superset of JavaScript developed by Microsoft. It adds static types, interfaces, and compile-time checking on top of JavaScript, then compiles down to plain JS that runs anywhere JavaScript runs.

The goal is to catch bugs before code ever runs, and to make large codebases easier to navigate, refactor, and understand through explicit types and tooling support.

    18 Error Handling

    try {
  JSON.parse(input);
} catch (err: unknown) {
  if (err instanceof Error) console.error(err.message);
}
  • TypeScript types caught errors as unknown by default — narrow before use.

    • 19 Memory Management

    TypeScript compiles to JavaScript, so it inherits JS's automatic garbage collection — there's no separate TS memory model.

    let data: number[] | null = [1,2,3];
data = null; // eligible for GC

    20 Performance

    • Use strict mode to catch bugs at compile time, not runtime.
    • Prefer interfaces over complex mapped types in hot paths for faster compilation.

    21 Best Practices

    • Enable strict: true in tsconfig.
    • Avoid any — prefer unknown with narrowing.
    • Use readonly for immutable data.

    22 Security

    • Types don't guarantee runtime safety — validate external data (API responses) with libraries like Zod.
    • Avoid as any casts that bypass type checks on user input.

    23 Accessibility

    • Type your component props to avoid missing required ARIA attributes.
    • Use typed event handlers for keyboard interactions.

    24 Code Style

    • PascalCase for types/interfaces/classes, camelCase for variables.
    • Prefer type for unions, interface for object shapes.

    28 Interview Questions

    Q: interface vs type?
    A: Interfaces are extendable and best for object shapes; types support unions/intersections.
    Q: What is structural typing?
    A: TS types compatibility by shape, not name — if it has the right properties, it fits.
