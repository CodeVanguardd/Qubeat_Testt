C#

A modern object-oriented language from Microsoft that blends elegance and performance across the .NET platform — games, web, and enterprise software.

1 Introduction

C# is a modern, object-oriented language developed by Microsoft that runs on the .NET platform. It blends the productivity of managed memory and rich tooling with strong typing and performance suitable for enterprise, cloud, and game development.

Type
Compiled (JIT/AOT), statically typed, OOP
Runs on
.NET runtime — Windows, Linux, macOS
Used for
Unity games, ASP.NET web apps, enterprise tools

2 History

C# was created by Anders Hejlsberg at Microsoft, released in 2000 alongside the .NET Framework, designed as a modern alternative combining C++ power with Java-like productivity.

  public override string Speak() => $"{Name} barks";
}

19 Memory Management

C# uses automatic garbage collection on the .NET runtime, with optional IDisposable/using for deterministic cleanup of unmanaged resources.

using (var f = new StreamReader("x.txt")) { }
// auto-disposed at end of block

20 Performance

  • Use Span<T> to avoid unnecessary allocations.
  • Prefer StringBuilder for heavy string concatenation.

21 Best Practices

  • Use async/await for I/O-bound work, never block with .Result.
  • Prefer dependency injection for testable code.

22 Security

  • Use parameterized queries (never string-concatenated SQL).
  • Validate and sanitize all user input, especially in ASP.NET controllers.

23 Accessibility

For WPF/WinForms/MAUI apps: set AutomationProperties.Name and support keyboard navigation.

24 Code Style

  • PascalCase for methods/classes/properties, camelCase for local variables.
  • Follow Microsoft's official C# coding conventions.

28 Interview Questions

Q: What is boxing/unboxing?
A: Boxing converts a value type to an object (heap); unboxing converts it back — both have performance cost.
Q: Value types vs reference types?
A: Value types (struct, int) copy on assignment; reference types (class) share the same underlying object.
